Reading room

A meta-prompting framework for agentic systems

A prompt is not a key. It is an operator.

Describe what your agent should do. Prometheus interviews you, designs the prompt section by section, audits it, and ships it as files you install, with a verifier.

Install the skill Enter the reading room

I · The principle

Meaning is not retrieved. It is constructed.

  1. Each section of a prompt is an operator. It amplifies some readings of your intent and suppresses others.
  2. Operators do not commute. The same sections in another order are another prompt.
  3. Ambiguity is not a defect. It is a superposition, held open until it is measured, and the interview is where you measure it.

Prometheus designs that sequence deliberately, then checks it.

II · The seven shapes

Seven shapes. Every prompt is one of them.

Prometheus infers the shape from what you ask for, then drafts on that shape's spine.

  1. I

    The Loop

    Agentic loop

    Work that returns to itself until the condition is met. Memory outlives the turn.

  2. II

    The Arrow

    One-shot task

    One call, one answer, the format fixed before the first word.

  3. III

    The Chain

    Workflow chain

    Stages that hand a file to the next. What is lost early cannot be recovered late.

  4. IV

    The Hand

    Sub-agent or tool

    A capability another agent reaches for. Its first line is the whole of its name.

  5. V

    The Mask

    System persona

    A voice that holds under pressure and knows what it refuses.

  6. VI

    The Scales

    LLM-as-judge

    Reasoning before the verdict, anchors at every level, and the honesty to say inconclusive.

  7. VII

    The Council

    Agent team

    Roles with walls between them, contracts on every door, one place where the state lives.

III · The rite

Six phases. Nothing ships unaudited.

  1. 01

    Shape

    Infer which of the seven shapes you are asking for, without a routing question.

  2. 02

    Interview

    Ask only what the request leaves open, one question at a time, broadest first.

  3. 03

    Draft

    Write each section as an operator, ordered by strength, checked for interference.

  4. 04

    Audit

    Run the checklist. Fix what fails, or ship with the gap named.

  5. 05

    Score

    Score the draft honestly on token economy, task fit and coherence.

  6. 06

    Deliver

    Ship the files, the usage notes and the verifier, checked in a fresh context first.

Every artifact ships with a verifier

  • Static — properties of the artifact itself.
  • Single-run — properties of one output.
  • Cross-run — patterns visible only across many, where regressions hide.

IV · The three modes

Build it, fix it, keep it alive.

  1. I

    From scratch

    You describe the task. Prometheus produces the prompt, the agent or the workflow.

  2. II

    Refactor

    You bring a prompt. Prometheus audits it, patches it, or rewrites it.

  3. III

    Manage

    You point at a running agent. Prometheus monitors, analyzes, adapts and restarts it, as a MAPE-K loop.

V · Ignite

Install it once. Describe what you need.

  1. Clone the repository.
  2. Copy it onto your agent's skill path.
  3. Describe a prompt, an agent or a workflow. The host routes to Prometheus on its own.
